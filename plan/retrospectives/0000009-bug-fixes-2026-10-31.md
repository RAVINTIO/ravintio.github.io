## Summary

Version 0.4.1 shipped six stories with all 13 criteria verified. One P2 stop for a dependency approval held the run for about 90 minutes.

## What helped

- Confirmed copy lived in its own file, so units applied it verbatim with no rewording loop (`agreed-copy.md` in the archive).
- A fresh-context reviewer found a test that only searched source text. The fix made it test behaviour. (build log `Improve:` line, commit `cb8b61f`)
- Each unit's test went RED before its change, so every criterion had a failing test first (build log `Done:` lines).

## What slowed the work

- A new advisory appeared between P0 and P2, and its fix fell outside the approved versions (build log `Blocked:` line, `plan/postmortems/2026-10-31-advisory-after-discovery.md`).
- Two 0.4.0 tests conflicted with the confirmed design and needed a human ruling (build log `Departure:` lines for U1).
- P2 ran every unit inline against the three-subagent rule, as run 0000005 did (build log `Departure:` lines in both archives).

## Keep

- An agreed-copy file for any run that changes confirmed text (`agreed-copy.md`).
- One fresh-context review across the whole diff (build log `Improve:` line).

## Change

- Give small content units a defined inline TDD path, so runs stop logging the same departure.
- Re-check dependency advisories before implement. The postmortem filed this.
