# Scope - web-app

## In scope

- Homepage layout and styling
- The 404 page `404.html`
- The build script `scripts/build-docs.js`
- The sectioned nav manifest `docs.manifest.json`
- Section nav, top nav, and previous and next links
- Logo, wordmark, and favicons
- Theme toggle and mobile menu
- Mermaid diagram rendering on demand
- Site tests in `tests/`
- The Playwright regression suite in `tests/e2e/`, with the axe-core scan
- The site workflows `site-tests.yml` and `deploy.yml`
- The inline theme script in each page template

## Out of scope

- Page text, owned by `site-content`
- Site search
- Doc versioning
- `.github/workflows/ravintio.yml`, which `ravintio-zero/setup.sh` writes

## Deferred

Nothing deferred.
