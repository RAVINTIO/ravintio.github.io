# Scope - web-app

## In scope

- Homepage layout and styling
- The build script `scripts/build-docs.js`
- The sectioned nav manifest `docs.manifest.json`
- Section nav, top nav, and previous and next links
- Logo, wordmark, and favicons
- Theme toggle and mobile menu
- Mermaid diagram rendering on demand
- Site tests in `tests/`

## Out of scope

- Page text, owned by `site-content`
- Site search
- Doc versioning

## Deferred

Nothing deferred.
