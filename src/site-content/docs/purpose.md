# Purpose - site-content

`site-content` owns the Markdown pages of the RAVINTIO docs site. Every text change on the site starts here.

## Why this component exists

Page text changes for different reasons than the build does. Keeping the pages in their own component gives them one owner and one place to edit.

## What it does

- Explains what RAVINTIO is and the principles behind the name.
- Describes the six tools with their status labels.
- Teaches readers to install RAVINTIO Zero and run a first feature.
- Lists every skill, standard, and template in the installed pack.

## What it does not do

- Build, style, or navigate the site. `web-app` does that.
- Document RAVINTIO Framework in full. Backlog entry `0000006` holds that work.
